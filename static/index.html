Each habit is priced or counted on its own; there is no overall score. A badge appears only where Anthropic gives a line to measure against. Its /usage flags long context and cache misses at 10% of recent usage; this tool applies that 10% line to its own measures (requests over 500k tokens; the cost of re-caching after the cache expired, expiry misses only), so those badges are the tool's reading, not Anthropic's verdict. Anthropic publishes ~$13 per active day as the average and $30 as the 90th percentile across its deployments: the spend badge shows where you sit against them, and neither is a target. Hover a card for how it is measured. These are for you; they are not a performance measure.

Limits come from the notices Claude Code writes when a limit stops a request; only the limit type and reset time are read from them. Locked out means nothing got through until the reset; otherwise “blocked” is just how long the notices kept coming. Dollar figures are list-price equivalents. Costs are estimates from public Anthropic API list pricing; the 1h cache-write rate is taken as 2× input, Anthropic's published multiplier. Fast-mode requests are priced at 2× and Batch-tier requests at 0.5×. Each API response is counted once, by its message id, across every transcript — Claude Code writes one line per part of a response, each repeating the full usage, which is why a count of lines reads high (streamed snapshots keep only the largest output; a fork/resume copy yields to the original). Includes subagents. Web search and fetch results are priced as the input tokens they add to the conversation; the search itself (billed per search on the API) and WebFetch's separate page-reading model call aren't in the transcripts. US-only inference (1.1×) isn't modelled.

Main-conversation spend by context size

Every request re-sends the whole conversation, so a long session costs more per message and, per Anthropic's context-engineering post, recall decreases as tokens grow: a performance gradient rather than a hard cliff. The 200k and 500k lines are this tool's own, not Anthropic's: its pricing has no tier at either (Claude 4.6 and later include the 1M window at standard pricing). Running out of room is rarer with 1M windows and automatic compaction, but /clear between unrelated tasks still keeps the large bands small.

Cache misses by Claude Code's reason

Extra paid over reading the same tokens from a warm cache. “Cache expired” is picking a session up after a break longer than the cache lasts; “model switched” is /model mid-session.
